# Презентация к питчу (3 минуты)

Интерактивная HTML-презентация для защиты трека 1 «Управленческая платформа» на Space Hackathon 2026.

## 🚀 Как открыть
Просто откройте файл в любом браузере:
```bash
open presentation/index.html
```
Или через запущенный локальный сервер:
[http://127.0.0.1:8000/presentation/index.html](http://127.0.0.1:8000/presentation/index.html) *(если статическая папка смонтирована)*

---

## 🎨 Дизайн и палитра
Дизайн выполнен в строгом современном стиле Linear/Vercel (Modern B2B Dark SaaS) на базе фирменной палитры заказчика:
- `#164A41` — Deep Forest Green (глубокий хвойно-изумрудный, премиальный фон карточек и поверхностей)
- `#4D774E` — Muted Moss Green (мшисто-зеленый, вторичные элементы и границы)
- `#9DC88D` — Light Sage (фисташково-мятный светлый, графики, индикаторы и бейджи)
- `#F1B24A` — Warm Amber / Gold (золотисто-янтарный, ключевые цифры метрик, акценты)
- `#FFFFFF` — Pure White (контрастная типографика)

## ⌨️ Управление во время выступления
| Клавиша | Действие |
|---|---|
| `→` / `Space` / `PageDown` | Следующий слайд |
| `←` / `PageUp` | Предыдущий слайд |
| `F` | Полноэкранный режим (Fullscreen) |
| `N` | Открыть / скрыть окно подсказок спикера (Presenter Notes) |
| `T` | Пауза / продолжение обратного отсчета 3 минут |

---
