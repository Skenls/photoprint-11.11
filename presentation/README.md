# Презентация к питчу (3 минуты) · 12 слайдов

Интерактивная HTML-презентация для защиты трека 1 «Управленческая платформа» на Space Hackathon 2026.
Брендбук PicPac: красный `#DD5757`, тёмный `#364C49`, тёплый фон `#F6EFE6`, лимонный `#FFE669`.

## Как открыть

```bash
open presentation/index.html
```

Навигация: `→`/`Space` — вперёд, `←` — назад, `Home`/`End` — начало/конец,
`F` — полноэкранный режим, `N` — заметки спикера, `T` — таймер 3:00, `Hash` (`#5`) — прямой слайд.

Печать / PDF: `Cmd+P` → «Сохранить как PDF» — 12 страниц 16:9 (в репозитории лежит готовый `Magi-PicPac-deck.pdf`).

## Дизайн

- редакционный стиль: крупная типографика (Futura PT / Avenir Next), много воздуха, один смысл на слайд;
- светлые и тёмные слайды чередуются для ритма, красный — только для главных акцентов и цифр;
- без тяжёлых библиотек: чистый HTML/CSS/JS, работает офлайн;
- референсы: современные pitch-колоды (Pitch.com «Scale-Up», «AI-Native», тренды 2026 — крупный заголовок, мягкие градиенты, минимальный декор).

## Содержимое папки

- `index.html` — презентация (16:9, клавиатура, заметки, таймер, печать);
- `Magi-PicPac-deck.pdf` — экспорт на 12 страниц;
- `pitch-script.md` — сценарий на 180 секунд с таймингами и ответами на вопросы;
- `README.md` — эта инструкция.
